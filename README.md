# Eevneons-Piercingly-Stunning-Spears
A visual overhaul of the newly added spears to soothe your eyes.

## Description
 
**Eevneon's Piercingly Stunning Spears** is a quite simple resource pack, changing the textures of the newly added spears. See the _gallery_ tab for a preview!


The changes include, but are not limited to:

- Enhancing the saturation of some shades and making sure hue shifting is applied properly. 
- The handles of all the spears now follow the colour palette of copper, so that the copper spear looks uniform.
- Some extra details as a kind of sub-handle underneath the tip of all gold, diamond and netherite spears.


> Do note that some colour palettes (specifically the diamond one) don't line up with vanilla textures anymore, but this negative does not outweigh the positives.
